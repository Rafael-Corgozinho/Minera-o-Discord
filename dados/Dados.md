# Dados do projeto

Os conjuntos de dados utilizados neste projeto estão armazenados no Google Drive, pois excedem os limites de tamanho de arquivos do GitHub.

**[Acessar os dados no Google Drive](https://drive.google.com/drive/folders/1OkTt9lWDsYIkXCeFDRM1wYd6tkryiJmp?usp=drive_link)**

Na pasta estão disponíveis os arquivos `dataset.zip` (base coletada) e `arquivoDB.zip` (banco de dados), conforme a organização do Drive.

Para executar as análises, baixe os arquivos necessários e consulte os caminhos indicados nos notebooks. Os dados não são versionados neste repositório.
